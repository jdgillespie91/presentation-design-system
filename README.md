# Presentation Design System

A skill for AI coding agents to generate standalone HTML slide presentations.

## What This Is

This repository contains a **skill** — instructions that AI coding agents use to create polished HTML presentations.

The skill produces single-file HTML presentations with:
- Dark gradient backgrounds with violet accents
- Glass morphism effects
- Keyboard navigation (arrow keys)
- 16:9 aspect ratio

## Usage

Ask your AI coding agent to create a presentation:

```
Create a presentation about our Q3 results with slides for:
- Title slide
- Key metrics (revenue, users, growth)
- Three main achievements
- Roadmap for Q4
```

The agent will read the skill files and generate a complete `.html` file you can open in any browser.

## Example Output

See `design-system.html` for a reference presentation showing all layouts and foundation elements.

## Viewing Presentations

Open any generated `.html` file in a browser. Navigate with:
- **Right Arrow** or **Spacebar**: Next slide
- **Left Arrow**: Previous slide
